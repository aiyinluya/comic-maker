# 微调 vs 提示词:教 AI 的两种姿势

> 码事漫谈 · AI 科普系列

## 引入

公司想让 AI 学会自家产品的口吻回答客服问题,该怎么做?团队里通常爆发两派争论:

- **提示词派**:写个说明文档塞给它就行,又快又便宜;
- **微调派**:拿一万条历史客服对话训练一下,它才能真正"长"成本公司的人。

两边都有道理,也都有人交过冤枉学费。这篇讲清楚两者的本质区别,以及那道选择难题的判断公式。

## 提示词:给 AI 写说明书

**提示词(Prompt)是你发给模型的全部指令**:任务描述、要求、示例、背景资料......它改变的是模型"这一次怎么回答",不改变模型本身。

打个比方:提示词是**给一个名校毕业生写岗位说明书**。他知识面广、学习能力顶配,你把要求写清楚、给两个范例,他当场就能干活。缺点也明显:

- 说明书只能带进会议室,**装不进他脑子里**--下次谈话还得重新念一遍(每次都占 token);
- 极其垂直的知识(比如你公司内部的暗语、三年前的项目代号)写不进说明书,塞太多反而干扰他。

适用于:通用能力 + 你的"现场指导"就能搞定的事。写文案、做总结、改代码、按模板回答--先试提示词,九成场景到此为止。

## 提示词的天花板在哪

提示词便宜好用,但它的能力边界要心里有数:

1. **它只能调用模型已有的知识**:模型训练数据里没有的东西(你公司内部流程、上周发生的事),提示词写得再好它也只能现编或靠你提供资料;
2. **它挤占 token 预算**:说明书越长,每次对话成本越高,而且和正文抢注意力--说明书超过一定长度,模型反而开始漏看要求;
3. **它不保证 100% 遵守**:提示词是"软约束",模型偶尔会忘记格式、漏掉条目。需要"硬约束"(万无一失的格式、一字不差的口径)时,要么微调,要么在程序侧做校验重试。

这三条边界分别对应三个升级方向:知识不够上 RAG、token 太贵上压缩/微调、软约束不够上程序化校验。

## 微调:送 AI 去读专科

**微调(Fine-tuning)是拿成批的训练数据(通常几百到几万条问答对)继续训练模型**,把特定能力"长"进模型参数里。

比方:**送毕业生去读专科**。学费不便宜(数据、算力、时间),但毕业之后:

- 岗位说明书不用念了,**上手就会**(省 token、响应快);
- 专科的本事稳定在脑子里,**不靠现场发挥**--这正是客服机器人、法律文书助手这类"每天答一万遍同样问题"场景最需要的稳定性。

代价也很清楚：要花钱跑训练、**改版要重训**（模型升级后微调可能要重来）、而且学过头会“偏科”——通用能力下降。

微调圈有句行话：**Garbage in, garbage out（垃圾进，垃圾出）**。几千条互相矛盾的对话，教出来的模型会比不教还乱。数据准备的三条底线：

1. **一致性**：同类问题的答案口径必须统一——如果历史客服记录里一半说“24 小时发货”一半说“48 小时”，微调出的模型就会看心情发货；
2. **覆盖度**：训练数据要覆盖真实用户会问的各种问法，而不是只有一个标准句式；
3. **干净度**：错字、语序混乱、答非所问的样本要清洗掉——每一条脏数据都会被模型“认真学会”。

所以微调的成本大头往往不是算力，是**整理数据的工程量**。这也是为什么说它是“重武器”：弹药贵，还得自己造。

## 一张表分清

| | 提示词 | 微调 |
|---|---|---|
| 改变什么 | 这一次的回答 | 模型本身 |
| 成本 | 几乎为零 | 数据+算力+时间 |
| 更新速度 | 改完立即生效 | 改数据要重训 |
| 知识装在哪 | 每次现场带入(占 token) | 长在参数里(不占) |
| 擅长 | 通用任务+现场规则 | 高频、垂直、格式稳定 |

## 选择公式:先便宜后昂贵,先软后硬

## 什么时候用微调,什么时候别碰

实战中的决策顺序几乎总是这样:

1. **先试提示词**(含 RAG 补知识):九成需求到这就结束了;
2. 提示词解决不了再问:是**知识不够**(去 RAG/联网检索),还是**行为不稳**(每问答法飘忽、格式老跑偏)?
3. 只有"**行为问题**"且长期高频,才上微调;
4. 两者常组合用:微调定"性格",提示词定"当天的任务"。

两个真实场景的对照:

- **该微调的**:客服机器人每天答一万遍"怎么退货",必须严格按公司口径、输出固定格式--这种"高频+稳定+垂直"的需求,微调一次全年受用;
- **不该微调的**:想让它"更懂我们公司"就微调了三千条内部文档--其实这是知识问题,用 RAG 外挂文档库就解决了,数据还能随文档更新实时生效,不像微调那样一锤子买卖。

一个反直觉的提醒:很多团队上微调,最后发现真正的问题是提示词没写好、或该上 RAG。**微调是重武器,别拿它打蚊子。**

## 要点小结

- **提示词 = 写说明书**:快、便宜、每次现场带入;改的是"这一次";
- **微调 = 读专科**:贵、稳定、能力长在参数里;改的是"模型本身";
- 决策顺序:提示词 → RAG 补知识 → 行为不稳才微调;
- 组合拳最常见:微调管底色,提示词管当天任务。
